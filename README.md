# Enchant Bypass

WoW Forever addon. Auto-confirms the Replace Enchant popup when you enchant an item that already has an enchant.

Repository: https://github.com/SultonMRP/EnchantBypass

## Install

Unzip `EnchantBypass` into `Interface\AddOns`. Restart the client once if it is a new folder.

## Use

`/epass` toggles. Default is off. The setting is saved. If it is on at login or `/reload`, chat prints orange **EnchantBypass is active**.

You still start the enchant (cast or drop the scroll). The addon clicks Yes on `REPLACE_TRADESKILL_ENCHANT` / `REPLACE_ENCHANT`.

It does not confirm bind, destroy, or delete dialogs.
